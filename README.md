# XUBAX — Odoo Apps

Módulos Odoo 19.0 publicados por **XUBAX** ([xubax.com](https://xubax.com) · soporte@xubax.com).

La rama `19.0` contiene el código para Odoo 19.0. Cada módulo vive en su propia carpeta en la raíz del repositorio.

## Módulos

| Módulo | Descripción | Licencia |
|---|---|---|
| `xb_delivery_signature` | Firma de "recibido" del cliente al entregar (albarán, portal web, PDF). Campos nativos de Odoo 19. | OPL-1 |
| `xb_delivery_signature_pos` | Puente que captura la firma de entrega desde el Punto de Venta y la espeja al albarán / orden de venta. `auto_install`. | OPL-1 |
