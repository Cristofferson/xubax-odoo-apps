Product Pricelist Rules – All Types & Search

See every pricelist rule on the product smart button — including formula (Cost + margin) and percentage rules — and search products inside any pricelist. Free, LGPL-3.

The problem in Odoo 18

The Pricelist Rules smart button on the product form only counts and opens rules computed as Fixed Price. Rules based on a formula or a percentage discount are hidden: the button shows 0 and opens an empty list, even when the product is used by many pricelist rules.

What you get

Feature Description
Complete count The smart button counts every rule applicable to the product or its variants (Fixed, Percentage, Formula).
Informative list Opens a list showing the pricelist, the computation method, the base, the margin and the resulting price — no meaningless "Fixed Price" column on formula rules.
Search inside a pricelist Every pricelist form gets a Search products / rules button that opens that pricelist's rules in a real searchable list — the built-in Price Rules tab is a plain scroll with no search box, unusable on pricelists holding thousands of rules.
Find rules by product The rules search view gains a Product field, so you can type a product name (not just group by it) to find its rules across the catalog or within a single pricelist.
Searchable menu Adds Sales » Products » Price Rules (search) to browse the full list of rules with filters and group-by (by product, pricelist, scope, dates…).
Zero config Install and it works. No data migration, no settings.
