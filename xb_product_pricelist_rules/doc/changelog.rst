Changelog
=========

18.0.1.2.0
----------

* New **Search products / rules** button on every pricelist form: opens that
  pricelist's rules in a searchable list (the built-in *Price Rules* tab has no
  search box).
* The rules search view gains a **Product** field, so rules can be found by
  typing a product name (matching product and variant rules), not only grouped.
* Spanish (es / es_MX) translation added.

18.0.1.0.0
----------

* Initial release.
* Pricelist Rules smart button counts and opens rules of every computation
  type (Fixed, Percentage, Formula), not only fixed-price ones.
* Informative list view for the smart button.
* New searchable menu *Sales ▸ Products ▸ Price Rules (search)*.
